1. How to Run the Project

The entire implementation is packaged into a single, standalone Python file with zero complex setup.

To execute the full algorithm, train the model, evaluate benchmark recognition accuracy, and validate the 4-way decision framework, open your terminal and run:

$ python3 main.py Runs standalone pipeline
Project Structure:
  • main.py : Contains all mathematical algorithms, PCA formulation, and demonstration logic.
  • data/olivetti_py3.pkz : The bundled AT&T / Olivetti benchmark dataset (400 face photos, 40 subjects).
  • index.html : This interactive code and results showcase document.
  • REPORT.html : Formal, black-and-white university submission report with certificates.

3. Algorithmic Code Walkthrough (From Scratch)

Line-by-line breakdown of the Python code in main.py alongside the original mathematical derivations.

1
Vectorization & Average Face Calculation
Ψ = (1 / M) Σ Γi

Each 2D facial image of size $N \times N$ ($64 \times 64$) is unrolled row-by-row into a high-dimensional vector $\Gamma_i \in \mathbb{R}^D$ where $D = 4096$. We compute the universal Mean Face $\Psi$, which acts as the common human baseline.

# 1. Reshape images to column vectors Gamma of shape (D, M) Gamma = X_train.reshape(M, D).T # (4096, 245) # 2. Compute Mean Face Vector Psi self.mean_face = np.mean(Gamma, axis=1) # Shape: (4096,)
Viva / Evaluation Tip: Why subtract the mean face? Subtracting $\Psi$ centers the dataset around the origin ($\mathbf{0}$), ensuring that PCA discovers the directions of maximum variation between individuals rather than common facial features.
2
Mean-Centering & Difference Matrix
Φi = Γi - Ψ   A = [Φ1, …, ΦM]

Subtracting $\Psi$ from each face gives the difference vector $\Phi_i$. Packing all $M$ difference vectors side-by-side produces the difference matrix $A \in \mathbb{R}^{D \times M}$.

# Mean-center difference matrix A of shape (D, M) A = Gamma - self.mean_face[:, np.newaxis] # (4096, 245)
3
The Turk-Pentland Covariance Reduction Trick
L = ATA ∈ ℝM × M   (instead of C = AAT ∈ ℝD × D)

The full pixel covariance matrix $C = \frac{1}{M} A A^T$ has dimensions $4096 \times 4096 = 16,777,216$ elements, which is computationally intractable. Turk & Pentland proved that the eigenvectors of $C$ can be found by decomposing the surrogate matrix $L = A^T A$ of size $245 \times 245 = 60,025$ elements (a $279\times$ reduction!).

# Compute surrogate covariance matrix L of size (M x M) L = np.dot(A.T, A) # Shape: (245, 245) # Solve for surrogate eigenvectors v_k: L * v_k = mu_k * v_k eigenvalues, eigenvectors = np.linalg.eigh(L) # Sort in descending order idx = np.argsort(eigenvalues)[::-1] eigenvalues = eigenvalues[idx] top_eigenvectors_v = eigenvectors[:, idx[:K]] # (245, K)
The Mathematical Proof: If $L v_k = \mu_k v_k$, multiplying both sides by $A$ gives $A(A^T A v_k) = \mu_k(A v_k) \implies (A A^T)(A v_k) = \mu_k (A v_k)$. Hence, $u_k = A v_k$ is an exact eigenvector of the true covariance matrix $C$!
4
Recovering True Eigenfaces & L2 Normalization
uk = (A vk) / ||A vk||2

Multiplying matrix $A$ by each surrogate eigenvector $v_k$ recovers the true 4096-dimensional eigenface vector $u_k$. Normalizing ensures that the basis vectors form an orthonormal subspace ($u_i^T u_j = \delta_{ij}$).

# Map surrogate eigenvectors back to full pixel space U = np.dot(A, top_eigenvectors_v) # Shape: (4096, K) # Normalize each column vector to unit L2 norm norms = np.linalg.norm(U, axis=0, keepdims=True) self.eigenfaces = U / norms # Shape: (4096, K)
5
Face Subspace Projection & Reconstruction
Ω = UT( Γ - Ψ )   Γhat = Ψ + U Ω

Any facial image is projected into Face Space by taking its dot product with the eigenfaces, compressing $4096$ raw pixel values into just $K=40$ scalar weights $\Omega = [\omega_1, \dots, \omega_K]^T$.

def project(self, image: np.ndarray) -> np.ndarray: # Compresses 4096 pixels into K coordinates phi = image.flatten() - self.mean_face return np.dot(self.eigenfaces.T, phi) # Shape: (K,) def reconstruct(self, omega: np.ndarray) -> np.ndarray: # Reconstructs full 4096-D image from K coordinates return self.mean_face + np.dot(self.eigenfaces, omega)
6
The 4-Way Decision Rule (Two Thresholds)
εd (DFFS) vs θf   εc (DIFS) vs θc

Turk and Pentland formulated two distinct distance measures to make recognition robust against non-faces and unseen subjects:

def predict(self, image: np.ndarray) -> dict: eps_d, eps_c, predicted_label = self.compute_distances(image) # Case 1: Distance from face space exceeds threshold -> NOT A FACE if eps_d >= self.theta_f: return {"decision": "NOT_A_FACE"} # Case 2: Near face space and near known centroid -> KNOWN FACE elif eps_c < self.theta_c: return {"decision": "KNOWN_FACE", "label": predicted_label} # Case 3: Near face space but far from all centroids -> UNKNOWN FACE else: return {"decision": "UNKNOWN_FACE"}

4. Experimental Results & Graphs

Visual and quantitative evaluation produced on the 400-face Olivetti benchmark dataset.

Figure 1: Mean Face & Top 15 Eigenfaces

The Mean Face $\Psi$ (top-left) captures the common human baseline. The first two eigenfaces ($u_1, u_2$) capture global lighting shifts, while subsequent ones encode facial features.

Figure 2: Scree Plot & Cumulative Variance

Eigenvalues decay exponentially. The first 10 components capture 60.2% variance; $K=40$ achieves 86.3% variance with a 99.02% reduction in storage dimensionality.

Figure 3: Progressive Face Reconstruction

Reconstruction convergence from $K=2$ (coarse shadow) to $K=5$ (contour), $K=10$ (facial features), and $K=40$ (sharp individual likeness with $\epsilon_d = 4.73$).

Figure 4: 2D Decision Space Geometry

Mapping $\epsilon_d$ (DFFS) against $\epsilon_c$ (DIFS). The two thresholds $\theta_f = 7.884$ and $\theta_c = 6.463$ divide the space into Known Faces, Unknown Faces, and Non-Faces.

Figure 5: Robustness Under Noise & Occlusion

Demonstrates resilience against severe Gaussian noise ($\sigma=0.25$) and regional blockages (eye bars / medical masks) thanks to holistic dot-product projection.

Figure 6: Accuracy & Error Tradeoff vs. K

Identification accuracy peaks and plateaus at 87.62% around $K=40-50$, confirming that tail components capture sensor noise rather than identity cues.
